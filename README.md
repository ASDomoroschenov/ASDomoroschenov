## 🔬 Научные и исследовательские проекты
- **[Модифицированная lattice-атака на RSA](https://github.com/ASDomoroschenov/rsa-lattice-attack)** - Выпускная Квалификационная работа. Реализация атаки на RSA Cotan and Teşeleanu с использованием частичной информации о младших битах закрытой экспоненты d. На основе теории из свежей научной [публикации](https://www.mdpi.com/2410-387X/8/4/44#B15-cryptography-08-00044) октября 2024 года реализована схема RSA Cotan and Teşeleanu и атака с использованием частичной информации о младших битах закрытой экспоненты d. Используется: Java, SageMath, Метод Копперсмита, алгоритм Ленстры-Ленстры-Ловаса, Гребнер базис, решетки, теорема Гудмана-Хаугрейва-Грэма, изоморфизм Китайской Теоремы об Остатках и т.д.

- **[Реализация комплексных метрик для классификации изображений](https://github.com/ASDomoroschenov/python-comparison-image)** - Данная работа была представлена на международной молодежной научной конференции "Гагаринские чтения", в которой были реализованы комплексные метрики для классификации изображений - сравнение изображений на основе волновых метрик (ДПФ - Дискретное Преобразование Фурье) - алгоритм NNC, структурное сравнение изображений SSIM, сравнение на основе седловых точек и дисперсии изображений - SIFT. Для наглядного сравнения алгоритмов и классификации изображений для пользователя предоставлен UI.

- **[Сравнение производительности реализаций АВЛ-Дерева](https://github.com/ASDomoroschenov/avl-tree-comparison)** - Сравнение двух реализаций структуры данных АВЛ-Дерево - реализация сбалансированного дерева на основе вычисления высот, реализация сбалансированного дерева предложенная Кнутом.

## 🎓 Курсовые работы
- **[Криптозащищенный мессенджер](https://github.com/ASDomoroschenov/cryptography-course-project)** - Сервис для безопасного обмена сообщениями. Для шифрования сообщений доступно несколько алгоритмов - DES, TripleDES, Rijndael, RSA, LOKI97, RC5. Для распределения ключей между клиентами используется алгоритм Диффи-Хелфмана. При реализации использовались следующие технологи - Java, Spring Boot, Spring Data, Spring Web Mvc, Kafka, Redis, Mongo, Vaadin, Docker, Docker Compose

- **[Система управления реляционными базами данных](https://github.com/ASDomoroschenov/relational-database-management-system)** - Сервис для управления реляционными базами данных на основе заданных коллекций данных. Для выбора коллекций данных доступны - АВЛ-Дерево, Красно-Черное дерево, Косое дерево, В-дерево. В реализации использованы поведенческие и структурные паттерны программирования на языке C++ и не только.

- **[Система управления базой данных Java](https://github.com/ASDomoroschenov/java-data-base-service)** - Система по управлению базой данных студентов на Java, с использованием JavaFX и TCP сокетов.
